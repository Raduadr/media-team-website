# Media Team Website

Welcome to the Media Team Website project! This repository contains the source code and assets for a professional media team's online presence.

## Project Structure

The project is organized as follows:

```
media-team-website
├── src
│   ├── index.html          # Main landing page
│   ├── pages
│   │   ├── projects.html   # Projects showcase (English)
│   │   ├── projects-ro.html
│   │   ├── tenebris.html  # Tenebris artists (English)
│   │   ├── tenebris-ro.html
│   │   └── contact.html    # Contact form and details
│   ├── css
│   │   └── styles.css      # Styles for the website
│   ├── js
│   │   └── main.js         # JavaScript functionality
│   └── assets
│       └── images          # Images used in the website
├── package.json            # NPM configuration file
└── README.md               # Project documentation
```

## Features

- **Projects Section**: Display of the media team's work and projects.
- **Tenebris Artists**: Artist profiles, album information, and embedded album playback.
- **Contact Section**: A form for users to get in touch with the team.
- **Responsive Design**: The website is designed to be mobile-friendly and accessible.

## Getting Started

To get a local copy up and running follow these simple steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/media-team-website.git
   ```

2. Navigate to the project directory:
   ```
   cd media-team-website
   ```

3. Install the necessary dependencies:
   ```
   npm install
   ```

4. Open `src/index.html` in your web browser to view the website.
